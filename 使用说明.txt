小马压缩 1.1 · 右键后台版

日常使用不需要软件主窗口：
1. 右击文件或文件夹 → 小马压缩 → 压成 ZIP / 压成 7z / 仅打包 ZIP。
2. 右击压缩包 → 小马压缩：解压到同名文件夹。
3. 加密压缩包 → 小马压缩：密码解压。只出现必要的密码输入框。
4. 密码、分卷或其他压缩方式 → 小马压缩 → 密码 / 分卷 / 更多压缩选项。
Windows 11 的经典菜单位于「显示更多选项」，也可选中项目后按 Shift+F10。
当前右键压缩菜单针对单个文件/文件夹；备用管理界面仍可批量处理。

右键任务只在处理期间出现托盘图标，可以右击它取消当前任务。
结束后图标自动退出，不常驻、不自启动、不联网、不收集数据。
默认输出到源文件旁，重名自动加序号，不覆盖已有结果。
解压到独立文件夹；包内只有同名根文件夹时自动减少一层重复嵌套。
取消或错误会清理当前任务临时结果；批量任务的已成功结果保留。
强制结束进程或断电可能留下 .xiaoma-work-*，确认退出后可手动清理。
最近结果保存在当前用户 LocalAppData/XiaomaArchive/last-operation.json，密码不写入日志。

ZIP、7z、TAR 可以创建；TAR 仅打包。
RAR、ZIP、7z、TAR、GZ、BZ2、XZ、ZSTD、CAB、ISO、WIM 等由独立 7-Zip 内核读取。
ZIP 极速模式按扩展名识别已压缩媒体，直接打包以减少无效计算。
需要压缩这些媒体时可选均衡/更小；文件名判断不能保证内容都已压缩。
7z 极速字典 512 KB，均衡 4 MB，更小 8 MB；最多两个线程。
ZIP 密码使用 AES-256，部分旧软件和 Windows 内置解压器不支持。
ZIP 密码只支持英文、数字、符号；中文密码请选 7z，同时加密目录。
密码只在任务内存及内核进程参数中使用，不保存到配置或日志。

分卷需全部在同一目录；RAR 第二卷会自动定位首卷，7z 分卷请选 .001。
危险路径、数据流、系统保留名、链接和目录联接会被拒绝。
目录最多 20 万条，源目录最多 100 万项；不同盘符源文件请分开处理。
根目录不能直接打包；输出位置必须在源文件夹之外。

备用管理界面（直接打开 exe 或传入压缩包）：
目录搜索/排序、选中解压、只读文本预览、包信息、ZIP/7z 增删、转换及校验。
双击目录筛选内容，「更多」返回全部条目；双击文件只预览文本，不执行文件。
文本预览最多 2 MB；ZIP/7z 修改先在副本完成并校验，原包保留为 .bak。
转换创建新包，不改源包；修改分卷及 RAR 不支持，可先转 ZIP/7z。
创建 RAR、损坏 RAR 修复、自解压 EXE 不属于用户确认的日常替代范围。

exe 必须保留旁边 engine 文件夹。无需 .NET、浏览器运行时或 WinRAR。
Windows 10/11 64 位；速度/内存依赖 CPU、磁盘、文件及格式，无法 0ms。
安装右键菜单.ps1 仅注册当前用户菜单和打开方式；卸载脚本可移除。
移动成品后需重新注册；默认关联由 Windows 管理，不绕过 UserChoice 校验。
